# 🏏 ESPN Statsguru Cricket Data Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard built using cricket statistics collected from ESPN Cricinfo Statsguru.

The dashboard enables users to analyze player performances in batting, bowling, and fielding through dynamic visualizations and KPI cards.

It demonstrates complete Data Analytics workflow including:

- Data Collection
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- Dashboard Design
- Business Insights

---

## 📊 Dashboard Pages

### 🏏 Batting Analysis

Analyzes batting performance using various batting metrics.

Key KPIs include:

- Total Runs
- Matches Played
- Innings
- Highest Score
- Batting Average
- Strike Rate
- Hundreds
- Fifties
- Ducks
- Boundary Statistics

Interactive player slicer allows comparison of individual player performances.

---

### 🎯 Bowling Analysis

Analyzes bowling performance across players.

Key KPIs include:

- Wickets
- Bowling Average
- Economy Rate
- Strike Rate
- Best Bowling Figures
- Maidens
- Overs Bowled
- Five Wicket Hauls

---

### 🧤 Fielding Analysis

Evaluates fielding contributions of players.

KPIs include:

- Catches
- Stumpings
- Dismissals
- Matches
- Fielding Efficiency

Cricket performance data contains numerous statistical measures that are difficult to analyze manually.

The objective of this dashboard is to transform raw player statistics into meaningful insights that help compare player performance across batting, bowling, and fielding.
